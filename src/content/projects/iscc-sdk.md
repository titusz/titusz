The `iscc-sdk` package provides a high-level Python SDK for creating ISCC codes from media
files. It builds on `iscc-core` and adds automatic format detection, metadata extraction,
and thumbnail generation.

Supported formats include PDF, DOCX, EPUB, JPEG, PNG, MP3, MP4, and many more. The SDK
handles the complexity of extracting text, images, and audio features from different file
formats and producing standardized ISCC identifiers.
