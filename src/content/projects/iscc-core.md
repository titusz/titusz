The `iscc-core` library is the Python reference implementation of the ISCC standard. It
provides the core algorithms for generating ISCC codes from digital content.

Features:

- Generate Meta-Code, Content-Code, Data-Code, and Instance-Code units
- Combine units into composite ISCC identifiers
- Cross-platform support (Linux, macOS, Windows)
- Comprehensive test suite with conformance tests
